# Ford E-350 Camper Conversion

This project documents the V1 conversion of a Ford E-350 shuttle bus into a camper between June and November 2026.

- `assets/progress/` contains 50 dated build-progress photos.
- `assets/v1/` contains 31 photos captured when V1 was completed on November 6, 2026.
- `assets/data/bus-log.xlsx` is the original activity and cost log.
- `assets/data/photo-manifest.json` maps every copied photo to its original filename, capture date, and build phase.

The website page intentionally summarizes the source log rather than duplicating the workbook's full item-level ledger.
