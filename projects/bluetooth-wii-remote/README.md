# Bluetooth Wii Remote

ESP32 Air Pointer — a Wii Remote–style Bluetooth HID mouse built with an ESP32, Adafruit BNO055 IMU, custom KiCAD PCBs, and a 3D-printed enclosure.

## Project Page

The live project page is in `index.html`. Detailed firmware notes and tuning parameters are in `assets/README.md`.
